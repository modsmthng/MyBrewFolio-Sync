# MyBrewFolio Apps

MyBrewFolio Sync connects your local GaggiMate machines to your private MyBrewFolio library.
It runs the same Rust SyncEngine as the desktop and Docker companions.

[![Add the MyBrewFolio app repository to Home Assistant](https://my.home-assistant.io/badges/supervisor_add_addon_repository.svg)](https://my.home-assistant.io/redirect/supervisor_add_addon_repository/?repository_url=https%3A%2F%2Fgithub.com%2Fmodsmthng%2FMyBrewFolio-Sync%23home-assistant)

Requires **Home Assistant OS**, on AMD64 or ARM64. In Settings → Apps → Install app → Repositories,
add `https://github.com/modsmthng/MyBrewFolio-Sync#home-assistant`, install **MyBrewFolio Sync**,
start it, then select **Open Web UI**. Enable **Start on boot** if desired.

Use [the setup guide](mybrewfolio_sync/DOCS.md) to connect your account and machines.
Home Assistant Container users should use the [standard Docker companion](https://github.com/modsmthng/MyBrewFolio-Sync/blob/main/docs/headless.md).

This branch is an automatically generated catalog of stable published Sync releases. Its URL and
app slug are permanent installation identities. Source code, bug reports and release notes live
in the [main Sync repository](https://github.com/modsmthng/MyBrewFolio-Sync).
