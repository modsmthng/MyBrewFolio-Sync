# MyBrewFolio Sync

Synchronize GaggiMate brews, profiles and Notes with your private MyBrewFolio library.
Connect existing or new machines through a small administrator-only Home Assistant web interface.

The app uses the same Rust engine as MyBrewFolio Sync for desktop and Docker. Automatic shot and
profile imports go toward MyBrewFolio. Optional two-way Notes and confirmed Profile Store installs
retain the existing review, backup and verification requirements.

See [setup, backups and troubleshooting](DOCS.md). Updates are managed by Home Assistant.
